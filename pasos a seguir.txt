  3. PRÓXIMO PASO CONCRETO (BLOQUE B — MIGRACIÓN DE TOOLING)
-------------------------------------------------------------------------------

  Backend -> uv:
    - Declarar dependencias reales en backend/pyproject.toml (tabla [project]
      a partir de requirements.txt).
    - Generar uv.lock con `uv sync`.
    - Verificar `uv run pytest -v tests/` y
      `uv run uvicorn app.main:app --reload`.
    - Mantener requirements.txt como artefacto GENERADO, no como fuente.

  Frontend -> pnpm:
    - `pnpm import` (package-lock.json -> pnpm-lock.yaml), luego `pnpm install`.
    - Verificar `pnpm run dev`. Borrar package-lock.json.

  Después: Bloques C (diagnóstico), D (fix de crashes), E (doc-sync).
